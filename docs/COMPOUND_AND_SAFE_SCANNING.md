# 複利・出金ガード / VISION型スキャン

## 仕組み
- 10万円からデモ検証を開始可能。
- 1口の維持基準150,000円、月3万円を出金上限とする。
- 出金提案は「月間上限残額」「当月確定純利益残額」「出金後も維持額を超える残高」の最小値。
- 口座残高が維持額未満なら出金0円。確定利益を口座内に残す。
- 含み益は出金原資に使わず、自動出金も行わない。
- 6口は維持額900,000円、月間出金上限180,000円。実際の出金は確定利益がある範囲だけ。

## 10万円からの例
1口の維持額は15万円です。10万円の段階では出金しません。残高15万円でも出金せず、残高18万円かつ当月確定純利益8万円なら最大3万円を提案し、出金後残高15万円を守ります。確定純利益が2万5千円なら提案額も最大2万5千円です。

## デモ用リスク初期値
- 1取引リスク0.25%、日次損失停止1%、ドローダウン停止5%
- 同時保有1、当日最大5取引、2連敗で停止
- 最低リスクリワード比1.5
- ナンピン、グリッド、マーチンゲール禁止
- 発注前にSL/TPが設定されていない注文を拒否
- ライブ取引禁止

## VISIONから採用する機能
複数銘柄を正規化指標で比較し、TREND_UP / TREND_DOWN / RANGE / BUBBLE / CRASH / SHOCK を分類。急変動、古いデータ、スプレッド過大、流動性不足はブロック。レンジは専用戦略の検証完了まで監視のみ。BUBBLE / CRASH / SHOCK は新規取引禁止。

## 接続前に必要なこと
この初期実装は純Pythonロジックで、MT5発注関数へは未接続。実接続にはブローカー固有の銘柄名、取引時間、契約サイズ、tick value / tick size、最小ロット、ロット刻み、注文応答コード、約定後のSL/TP確認が必要。暗号資産現物、実株、現金はMT5のCFDと同一視せず別アダプターに分離する。

**デモ検証専用。利益・勝率・元本保全は保証しない。**
